Purpose of the project: 

We intend to create a magic 8-ball app that functions similarly to the classical magic 8-balls. We’re thinking about maybe trying to include some sort of voice recognition if possible, so that you could ask a question, the voice recognition is not necessarily intended for the program to register the question, but rather to register the use of the “8-ball”. Then the user can shake the “8-ball” and get an answer, however if someone does not wish to shake their phone in fear of losing it, the option to tap for an answer will be available as well. There would then be some sort of sound, and potentially a visual, indicating that it is in the process of being shaken and once it stops an answer will show up on the screen.

There will be different answers available that will trigger by chance. Some standard answers available will be yes and no and some variations of the affirmative and negative, but also other more complex answers, just like a real magic 8-ball would do. We intend to give different answers than the original magic 8-ball allows for, to make it a little more modern and to have some interactions that could potentially be funnier. We also intend to create some graphics for the app, so that it wouldn’t just be a black background with some text on it, but have something more visual as well.

We have also considered making a fortune-teller machine tap that would work similarly to the old carnival’s fortune teller machines, where someone pops in a coin and it prints out a fortune. In our version it would just be a tap on the screen, allowing the user to get a fortune on screen.

How it fulfills the requirements:

Since we’re making an app for Android devices, the requirements are 2 activities and 1 sensor. For the 8-ball app, the sensor that would be used is an accelerometer which is built into the phone. This would be used when shaking your phone to get the answer from the 8-ball.
The first activity is the initial app home screen, where you can choose whether you want to enter the 8-ball or the fortune teller. The next activity is activated when you choose one or the other.
